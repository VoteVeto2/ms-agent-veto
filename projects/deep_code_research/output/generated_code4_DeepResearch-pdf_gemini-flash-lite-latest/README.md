# Deep Research System Architecture Simulation

This project implements a conceptual architecture inspired by the processes described in the hypothetical `DeepResearch.pdf` document. It simulates a sophisticated AI system designed to tackle complex research questions by employing structured planning, iterative information acquisition, robust memory management, and final answer synthesis.

## 1. Project Title and Description

**Title:** Deep Research System (DRS) Simulator

**Description:**
The Deep Research System (DRS) is designed to mimic advanced cognitive architectures for deep, multi-step research. It breaks down a complex initial query into manageable sub-tasks using a **Query Planner**, gathers external evidence via an **Information Acquisition** module, manages the gathered facts and potential conflicts in a **Memory Manager**, and finally synthesizes a comprehensive, evidence-backed answer using an **Answer Generator**. This structure emphasizes modularity, iterative refinement, and structured data flow.

## 2. Installation Instructions

### Prerequisites
You must have Python 3.8+ installed.

### Setup
1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd deep-research-system
   ```

2. **Install Dependencies:**
   This project requires the `openai` library (for LLM interaction simulation) and `pydantic` (for structured data handling).

   ```bash
   pip install -r requirements.txt
   ```

3. **API Key Configuration (Crucial):**
   This system relies on an external LLM provider (simulated via `openai`). You must set your API key as an environment variable.

   **For Linux/macOS:**
   ```bash
   export OPENAI_API_KEY="YOUR_API_KEY_HERE"
   ```
   **For Windows (Command Prompt):**
   ```bash
   set OPENAI_API_KEY="YOUR_API_KEY_HERE"
   ```

## 3. Usage Examples

The primary way to interact with the system is through the main entry point script.

### Running a Sample Research Query

The `src/main.py` script initializes the system and executes a predefined, complex research task.

```bash
python src/main.py
```

**Expected Output:**
The script will print the steps taken by the system, including:
1. The initial query decomposition by the Query Planner.
2. The results of information acquisition attempts.
3. The final synthesized answer generated by the Answer Generator.

### Customizing the Query

To run a different query, modify the `complex_query` variable within `src/main.py` and then run the script again.

## 5. API Documentation (Component Overview)

The system is orchestrated via the `DeepResearchSystem` class in `src/deep_research_system.py`.

| Component File | Role | Key Responsibilities |
| :--- | :--- | :--- |
| `llm_interface.py` | **LLM Interface** | Provides standardized methods (`call_model`, `generate_structured_output`) to interact with the underlying LLM (e.g., OpenAI). |
| `query_planning.py` | **Query Planner** | Decomposes the initial complex prompt into a sequence or parallel set of actionable sub-queries. |
| `information_acquisition.py` | **Information Acquisition** | Executes the sub-queries, simulates tool use (e.g., web search), and retrieves raw data/evidence. |
| `memory_management.py` | **Memory Manager** | Stores acquired facts, assigns confidence scores, and handles the resolution of contradictory information before synthesis. |
| `answer_generation.py` | **Answer Generator** | Takes the validated, consolidated memory context and synthesizes the final, coherent long-form response. |
| `deep_research_system.py` | **Orchestrator** | Manages the flow: Plan $\rightarrow$ Acquire $\rightarrow$ Store/Resolve $\rightarrow$ Generate. |

### Core Data Flow (Conceptual)

1. **Input:** Complex Query
2. **Step 1 (Planning):** `DeepResearchSystem` calls `QueryPlanner`.
3. **Step 2 (Acquisition):** `DeepResearchSystem` iterates through sub-queries, calling `InformationAcquisition` tools.
4. **Step 3 (Memory):** Acquired data is passed to `MemoryManager` for validation and storage.
5. **Step 4 (Synthesis):** The final, clean context from Memory is passed to `AnswerGenerator`.
6. **Output:** Final Research Report.
